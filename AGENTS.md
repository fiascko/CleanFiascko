A collection of personal AI agent skills reflecting Fiascko's coding style, development practices, and workflows.

- [fiascko-philosophy](skills/fiascko-philosophy/SKILL.md) - General development philosophy, coding standards, and collaboration workflow.
- [unity-development](skills/unity-development/SKILL.md) - Unity and C# development practices, serialized references, performance, and architecture.
- [web-development](skills/web-development/SKILL.md) - Web development practices, vanilla technologies, performance, accessibility, and security.
- [database-development](skills/database-development/SKILL.md) - Database design, queries, data integrity, security, and strict read-only execution.

## Instructions

- Identify and read relevant skills before working on a task.
- Always apply `fiascko-philosophy` to development tasks, alongside `unity-development`, `web-development`, or `database-development` when relevant.
- Combine compatible skills when necessary.
- Follow the instructions defined in each applicable skill.
